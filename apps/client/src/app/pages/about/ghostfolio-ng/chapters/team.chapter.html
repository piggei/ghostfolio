The Ghostfolio-NG Team

Ghostfolio-NG is an independently maintained distribution of Ghostfolio that extends the original open-source project with additional portfolio management, financial analysis and usability features.

The project combines hands-on software development with AI-assisted analysis, implementation, testing and technical review. Codex and ChatGPT are AI assistants, not human contributors.

PJ — Project maintainer and developer

PJ coordinates Ghostfolio-NG development, defines requirements, designs and validates features, and oversees integration, testing and release decisions.

Codex — AI development assistant

Codex supports implementation, code analysis, automated testing, debugging and verification of changes.

ChatGPT — AI analysis and design assistant

ChatGPT supports technical planning, architectural analysis, financial reasoning, documentation and code review.

Ghostfolio-NG builds on the original Ghostfolio open-source project and the work of its contributors. It is an independent distribution, not an official upstream edition or a replacement for the upstream project.
